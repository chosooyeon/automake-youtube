## 이미지 프롬프트 사용법
1. `05-visual/output.json` 의 각 씬 `layers[].prompt` 그대로 복사
2. 이미지 생성 도구에 붙여 넣기 (Gemini · Imagen · Flux · Midjourney 등)
3. 16:9 비율, 1920×1080 (또는 그보다 큰 해상도) 로 생성
4. 결과 PNG 를 `asset_path` 경로(`05-visual/scenes/scene-XXX/img-XX.png`)에 저장
5. CapCut 에서 import → 텍스트 레이어/자막은 별도로 추가

## 톤 일관성 가이드
- **사진사실주의(photorealistic) cinematic** 베이스. 카툰/애니/네온/사이버펑크 X.
- 인물 얼굴 클로즈업 X (썸네일에서만 사용). 손·실루엣·뒷모습은 OK.
- 따뜻한 키 라이트 (golden hour, tungsten, warm rim). 식탁 메타포는 옵션이지 강제 X.
- negative_prompt 에 항상 `robot, brain illustration, watermark, cartoon` 포함.
