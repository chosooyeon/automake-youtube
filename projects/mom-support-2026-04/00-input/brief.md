# Brief — `mom-support-2026-04`

## 1. 주제 / 핵심 키워드
2026년 4월 기준, 임산부와 예비 부모가 **놓치면 안 되는 정부지원금** 총정리

## 2. 영상 한 줄 요약
"2026년 4월, 임산부가 받을 수 있는 정부지원금 — 신청 시기·금액·서류를 한 번에 정리"

## 3. 타겟 시청자
- 임신 12주~출산 직전 임산부 본인 또는 배우자
- 25~39세, 첫째 출산이 많음
- 정보 탐색 의지는 있지만 행정용어·신청 절차에 약함
- 카페·블로그를 주로 보다 유튜브로 재확인하러 옴

## 4. 톤
- 친근하지만 **정확**하게
- "공돈", "100% 보장", "안 받으면 손해" 같은 자극적 표현 금지
- "2026년 4월 기준", "신청 기한", "지원 대상" 같은 명확 표현 우선
- 광고/협찬/내돈내산 어휘 금지

## 5. 길이
6~7분 (롱폼)

## 6. 반드시 다뤄야 할 것
- **첫만남이용권** (200만원, 둘째 이상 300만원) — 출생일 기준 1년 내 신청
- **부모급여** (0세 월 100만원, 1세 월 50만원, 2026년 기준 확정 금액)
- **임신·출산 진료비 바우처(국민행복카드)** — 단태아 100만원, 다태아 140만원
- **양육수당/아동수당** (만 8세 미만 월 10만원)
- **임산부 친환경농산물 꾸러미** 지자체별 지원 여부
- **고위험 임산부 의료비 지원**
- **출산 전·후 휴가 급여 / 배우자 출산휴가 급여** (고용보험)
- **지자체 출산축하금** (지역별 차이가 큼 → 영상에선 "본인 거주지 확인" 으로 가이드)
- **신청 채널**: 정부24, 복지로, 주민센터, 임신육아종합포털 ‘아이사랑’

## 7. 절대 다루지 말 것 / 금지어
- 정확하지 않은 금액 단정 (모르면 "지자체별 상이")
- 특정 보험사·금융상품 추천
- "이거 안 받으면 손해" 류 자극적 카피
- 광고, 협찬, 내돈내산

## 8. 레퍼런스 (선택)
> 01번 봇이 자체 검색하되, 정책 출처는 반드시 공식 사이트 우선:
> - korea.kr / mohw.go.kr / bokjiro.go.kr / childcare.go.kr / gov.kr

## 9. 비고
- 정책은 매년 변경 → 영상 본문·제목·고정댓글에 **"2026년 4월 27일 기준"** 명시 필수
- 채널 시리즈 1편 (다음 편: "출산 후 1년간 받을 수 있는 모든 지원금")
- 썸네일은 Gemini 나노바나나 웹UI로 사용자가 직접 생성 (봇은 프롬프트만 제공)
- 음성은 CapCut 내장 TTS 사용 (외부 TTS API 호출 X)
